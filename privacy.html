Privacy Policy

Hermes Personal · Last updated: October 8, 2026

Hermes Personal is a private assistant used only by its owner. This policy explains which Google user data the app accesses, how it is used, and how it is protected.

Google data the app accesses

ScopePurpose
https://www.googleapis.com/auth/driveRead, create and update the owner's personal notes in the owner's Google Drive.
https://www.googleapis.com/auth/spreadsheetsRead and update the owner's own spreadsheets (personal budgeting).
https://www.googleapis.com/auth/calendarRead the owner's schedule and create events the owner requests.
https://www.googleapis.com/auth/gmail.readonlyRead the owner's email to summarize it for the owner.
https://www.googleapis.com/auth/gmail.sendSend email only when the owner explicitly asks.

How data is used

  • Data is used only to perform tasks the owner requests, for the owner.
  • Data is not sold, not shared with third parties, and not used for advertising.
  • Data is not used to train generalized AI or machine-learning models.
  • Only the owner's own Google accounts sign in; no other user's data is accessed.

Storage and security

OAuth tokens are stored on the owner's private server with access restricted to the owner. Content read from Google services is processed only as needed to complete a request.

Limited Use

Hermes Personal's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
